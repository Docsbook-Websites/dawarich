# Getting Started with Dawarich

Whether you self-host or use the cloud, the first three things are the same: point a tracker at your instance, import what you already have, and check you can get it back out.

## Set up tracking

- [Track Your Location](./track-your-location.md) — Set up location tracking using the Dawarich app, Overland, OwnTracks, Traccar, or GPSLogger mobile {navigation}
- [Dawarich for iOS](./dawarich-for-ios.md) — Install and set up the Dawarich iOS app for location tracking on iPhone and iPad {smartphone}
- [Dawarich for Android](./dawarich-for-android.md) — Install and set up the Dawarich Android app for location tracking on Android devices {tablet-smartphone}
- [Tracking with Shortcuts](./ios-shortcuts-automation.md) — Automate Dawarich iOS location tracking using Apple Shortcuts for time- and location-based triggers {zap}

## Your data

- [Import Existing Data](./import-existing-data.md) — Import location history from Google Takeout, OwnTracks, GPX files, and other sources into Dawarich {upload}
- [Exporting Your Data](./export-your-data.md) — Export your location data from Dawarich in OwnTracks-compatible JSON format for backup or external use {download}
