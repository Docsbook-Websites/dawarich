Dawarich is a privacy-first alternative to Google Timeline. Import a decade of location history, keep tracking from your phone, and own the result — on your own server for free, or in the cloud if you would rather not run one.

## New here?

If you are deciding whether to self-host, read [the self-hosting introduction](./self-hosting/introduction.md) and the [hardware requirements](./self-hosting/hardware-requirements.md) first — Dawarich runs happily on 2GB of RAM and a single core, on AMD64 or ARM64.

If you already have location history somewhere else, start with [Import existing data](./getting-started/import-existing-data.md). Google Takeout, GPX, GeoJSON and OwnTracks are all supported, and duplicate points are skipped automatically, so there is no harm in trying an import twice.
